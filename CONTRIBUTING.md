# Contributing

Thanks for helping improve this SQL learning repository!

## Before contributing

- Check whether the topic already exists.
- Keep examples compatible with the MySQL version stated in the README.
- Test SQL in a local practice database before submitting.
- Never use real credentials or private data in examples.

## SQL lesson requirements

For each new topic, add both:
1. A numbered `.sql` file under `sql/`.
2. A matching `_explanation.txt` file under `explanations/`.

The explanation should cover the purpose, important syntax, expected result, and a small practice task where appropriate. Keep examples small and beginner-friendly.

## Pull request checklist

- [ ] The SQL example has been tested or its limitations are clearly stated.
- [ ] The explanation matches the SQL file.
- [ ] Destructive commands are clearly marked and scoped.
- [ ] No credentials, tokens, or private data are included.
- [ ] README navigation or topic lists are updated if needed.
- [ ] The change is focused and the pull request description explains why it helps learners.

## Style

Use descriptive file names, consistent formatting, and comments for non-obvious behaviour. Prefer safe, reproducible examples over clever but hard-to-understand SQL.
